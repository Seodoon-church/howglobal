## 10. Search Console 제품 스니펫 구조화 데이터 오류 수정 (2026-08-26)
- **증상**: GSC가 "제품 스니펫 구조화된 데이터 문제 1개" 심각 오류 통지 — `'offers', 'review' 또는 'aggregateRating'을(를) 지정해야 합니다`.
- **원인**: `business.html`의 JSON-LD `ItemList`에 `@type:"Product"` 항목 2개(바이오타맥스·Painfree 8800)가 있으나, Google Product 리치 결과 필수 속성(offers/review/aggregateRating)이 하나도 없음. 소스는 `tools/build.py`의 `prod_ld`.
- **판단**: 이 제품들은 하우 사이트에서 **판매하지 않고 외부 사이트로 링크만** 함(e-commerce 아님). 가격·리뷰 데이터 없음. 가짜 offers/평점 삽입은 **Google 정책 위반**이므로 배제. Product 리치 결과는 어차피 offers 없이는 노출 안 되어 SEO 손실 없음.
- **조치**: `prod_ld`의 각 항목 `@type:"Product"` → `"ListItem"`(name + url)로 변경, `description` 제거, ItemList에 `name` 추가. Product 검증 대상에서 벗어남 → 오류 해소. `npm run build`로 `business.html` 재생성 확인(`Product` 문자열 소멸, `ListItem`으로 대체).
- **남은 작업(사용자)**: Hosting 배포(`deploy:hosting`) 후 GSC에서 해당 오류 **"수정을 확인했습니다"** 클릭(재검증 요청). 재검증까지 수일 소요.
